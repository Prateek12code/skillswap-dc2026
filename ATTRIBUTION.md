# Third-Party Resources

## Supabase

Used for email/password authentication, PostgreSQL database access, Row Level Security and Realtime channels.
https://supabase.com/

## Vite

Used as the development server and build tool.
https://vite.dev/

## Browser WebRTC APIs

The browser's native `RTCPeerConnection` and `getUserMedia` APIs are used for peer-to-peer video and audio calls.

## Google public STUN servers

`stun.l.google.com:19302` and `stun1.l.google.com:19302` are used only for WebRTC NAT discovery. No Jitsi integration is used in the final version.
